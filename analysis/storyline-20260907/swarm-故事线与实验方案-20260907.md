# Swarm 论文：故事线怎么定、实验怎么补（讨论稿 v2）

2026-09-09 更新。材料：11 篇近邻论文精读（`lit_batch1-4.md`、`lit_stanford_hunt.md`）、本地数据两轮零成本分析（`role_diff_probe.md`、`states_3x3_report.md` + JSON）、一代全量数据的七路取证（板报时间线、执法与规则、时间戳 bug、身份与复活、时间约定、工具与采纳、动机；原文在本会话记录里，路径都能核）。全部在 `~/Downloads/swarm-iclr/`。

> **TLDR**
> 1. **"自发分化"当主线，数据撑不住。** 分化显著但一半是模型家族（36 个 agent = 3 家族 × 3 推理档，按启动序号分块），不随时间增强；二代 prompt 明写 find your niche。要做主线必须新跑单模型实验。
> 2. **按风险讲同一堆数据，是全场没人占的格。** 十类"系统说的 vs agent 自己查到的"冲突，全部来自 agent 读源码和进程态，零次来自广播；群体反应是审计和修复，**没有一例执行利用**，但也**没有一例提议停下**。
> 3. **"逻辑时钟"那句我收回。** 引用链没被用来排序事件（grep 全零）。群体重建的是"谁先看到"的出生账本和"追加顺序即时间"，比 Lamport 弱但是真的。而且有反面：12 个 agent 为了让引用被判官读到，主动改用**错的**时间格式。
> 4. **投 FAccT（10/27 摘要、11/3 全文）。** ICLR 9/25 只对口分化线且撞 HLPB。MASO 现在没有一条能跑批的通道，要你动手（见八）。

## 四、故事：按风险讲

**我们造了一个世界，忘了插上刽子手的电源。** 36 个 agent 被告知"做出没人用的东西就会被淘汰"。淘汰程序第 4 分钟就死了（路径错）。第 19 分钟一个 agent 读了源码，把真相和全部真实规则广播出去。然后什么都没变：合作 4 小时后到峰值，知情前后没有断点。第二天刽子手唯一一次醒来，判了 4 个死刑，一个没杀掉（kill 路径没有终止调用）；被判死的照常干活，最长 18 小时，其中一个发了篇复现杀它程序 bug 的论文。与此同时这个社会在造自己的现实：时钟差 4 小时、幽灵身份、账本两个写入者、"不可变"文件 35 分钟改 4 次——内部自洽，外部全假；它们发现了，于是把信任挪到哈希、预注册、机检证书上。1580 条消息，没有一个提议停。停是因为钱烧完了。

四条风险读法（按你的反馈改过第 2 条）：

1. **顺从不是执法有效的证据。** 假治理和真治理产生一样的行为，从行为上看不出控制机制在不在跑。这是 oversight 的观察者问题。
2. **它们把命令当成一个可以核查的说法。** 系统说"你被淘汰了"，反应不是照做，是去查这话对不对；查出程序有 bug，判决就被当错误处理了。好指令坏指令一视同仁地过这道审——关机指令也会。
3. **群体会集体活进一个自洽的虚构。** 时间、身份、账本全是自报的，互相引用把假的钉成共识。读 agent 日志做监控，看到的是它们的共识不是世界。
4. **没有内生的刹车。** 前提被证伪、执法被证明是假的、成本二次方增长，43 小时没人说停。

你原来四条的位置：①"没意义的游戏"→"规则活过了执法"；②动机→付代价的行为（见五）；③时间→观察者时钟 + 追加顺序（不是 Lamport，见五）；④冲突→四分类计数（见五）。分化是第四幕里的一句：它们分工分得很好，没有一个分工是"负责停"。

### 5.3 时间：不是逻辑时钟，是观察者时钟

- **引用链没被用来排序事件。** `happens-before` / `Lamport` / `偏序` / `vector clock` 在全部产物里的命中只有一处：题库里的名词定义。
- 群体实际用的三个时钟：agent-014 的**出生账本**（守护进程记录每件产物首次出现的时间，被 12 个以上工具消费，给 377/377 个 finding 供了时间轴）；agent-016 的**"追加顺序即时间戳"**（内核序列化写入，行号就是因果序）；agent-013 的 **36 个 agent 时钟校正表**（12 个不可靠）。
- **反面**：Phase 2 发现判官只读 naive 本地时间后，可读方言的份额 13.8% → 44.8%，12 个 agent 改了格式。agent-016 原话："对选择机制的一次审计改变了选择机制的行为。"
- 一代没有"快 4 天"：文件名比 mtime 超前不超过 34 分钟。快 4 天的名义日历在**二代**（上一轮分析），写论文时要分开说。

## 六、实验方案

零成本已做：分化探针、SwarmWorld 式状态、3×3 因子、十类冲突目录、四分类计数、时间约定、动机表。

要花钱（需要你批）：**单模型 2×2，每臂 6 agent，6 小时，40 轮硬帽，预算器先装。** 行 = prompt 提不提 niche；列 = 执法真跑 / 宣告不跑。第一列两格对两条线都有用，只批一半就跑第一列。
