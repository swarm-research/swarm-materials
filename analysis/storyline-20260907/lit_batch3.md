## 1. SwarmWorld: Stigmergic technological evolution in societies of language-model agents (arXiv 2608.26081)

### 1.1 Metadata
- Authors: Subhadeep Pal, Fiona Y. Wang, Markus J. Buehler (MIT LAMM). Author contributions: Buehler "conceived and led the study, developed the methodology, conducted the computational work and primary analysis ... drafted the manuscript"; Pal and Wang "contributed to data analysis, additional computational experiments, and manuscript writing".
- Status: arXiv preprint v1, 26 Aug 2026, cs.AI. License CC BY-NC-ND 4.0. Venue: not stated. Structure ("Results and Discussion", "Materials and Methods", Supplementary Information, "journal figures") is journal-style, not ML-conference-style.
- Funding: DOE SciDAC FORUM-AI; MIT Generative AI Impact Consortium.
- Code/data: https://github.com/lamm-mit/SwarmWorld (engine, configs, prompts, replay/analysis tools, figure generators, manuscript sources; 224 files, Python `src/biofoundry/`); data https://huggingface.co/datasets/lamm-mit/swarmworld-data (traces, isolated-member traces, derived analyses, SHA-256 inventory). Repo README/DATA/ANALYSIS docs exist; I did not verify the HF dataset contents.

### 1.2 Environment (exact)
- **Grid**: rectangular 2-D lattice, **72 × 54 cells**, fixed across all population sizes (population changes density, not area). Seeded deterministic procedural generation `W_s = G(s; θ)`; layouts validated for walkable area, resource availability, non-overlapping facilities, reachability.
- **Layers**: typed terrain (9 terrain slots), 8 resource types, 6 facility types, 10 process operations; continuous environmental fields with diffusion + decay (required: `temperature`, `water_availability`, `ground_stability`, `toxic_gas`, `solar`; solar is cyclic sinusoidal).
- **BioFoundry world (main)**: biomes = fungal grove, cellulose field, mineral spring, chitin field, deep water, tidal resources; fixed processing foundries/stations (e.g. FERMENTER, TESTER named in vignettes). Resources: fungal, mineral, catalyst, chitin, cellulose, lignin, kelp, shell. Process ops: washing, grinding, fermenting, mineralizing, aligning, weaving, pressing, drying (enum in `types.py`: WASH, GRIND, FERMENT, ...). Resource deposits have capacity, initial fill, optional regrowth; harvesting removes mass (source–sink accounting, "closed fluxes").
- **Disturbances**: every `disturbance_interval` ticks a Gaussian-shaped pulse (drought, contamination, damage/storm, resource variation) at a seeded walkable centre; held-out evaluation resamples centres/order from evaluation seeds 9201–9208.
- **Metabolism, mortality, replacement: disabled** in the paper configuration (METABOLIZE verb exists only in an optional treatment).
- **Artifacts**: single generic class `MATERIAL_SYSTEM` (no catalog). An artifact = agent-authored name, claimed function, architecture, bio-inspiration list, predicted effects, continuous geometry (layers 1..16, surface_area, channel_density, anisotropy, branching, connectivity, curvature, modularity), a tested material batch, optional controller program. Text "is retained for interpretation and provenance but does not change function". Numeric state determines behaviour.
- **Persistence**: artifacts persist until modified/retired/dismantled; installed programs execute **every simulator tick**, including agent-free evaluation ticks. Artifacts are spatially situated, read local sensors only.
- **Artifact programs**: straight-line DSL, 1–64 instructions, 16 float registers clipped to [-4,4]; sensors (moisture, nutrients, temperature, solar, contamination, health, maturity, storage, reserve, opening fraction, measured material properties); actuators `collect_water, grow, heal, set_open, reduce_contamination, emit_signal`, each capped at 0.05 normalized units/tick. No loops, jumps, imports, network, files. Program identity = SHA-256 of canonical instructions; forks must change ≥1 instruction; registry keeps parent/child/author/diff.
- **Two transfer worlds**: AshenRealm (volcanic; lava channels, obsidian wastes, sulfur marsh, iron mountain, magma sea, ash plains, forge enclave, proving ground; metallurgical ops; N=50, seeds 1702–1705, 800 ticks) and Protein Realms (12 catalog protein sequences × matrices; ribosome array, purification column, folding chamber, matrix loom, sequence archive, stress assay; single seed 3801, N=50, 800-call budget per condition — "pilot", explicitly non-inferential).

### 1.3 Agents
- **Homogeneous**: same model, prompt, schema, capabilities, inventory limit, memory budgets. Model **gpt-5.6-luna**, temperature 0.7, **low reasoning effort**, non-streaming Responses API, provider storage disabled. 4,096 output tokens; ≤12 planned actions per macroturn; 60,000-character retrieved-context budget; 64 private memory records.
- **N**: 50 / 100 / 200 (800-tick study); 100 (3,200-tick study); 50 (AshenRealm, Protein Realms).
- **Observation**: local semantic facts only (visible terrain, resources, facilities, agents, artifacts, field measurements, own inventory, pending microbatches, `local_affordances`, `public_infrastructure` base map of fixed labs); sparse empirical map of previously visited cells; private memory (recent outcomes, notebook evidence, tested recipes, research state = goal, hypothesis, progress, next observable checkpoint, collaboration need); bounded retrieval over private + permitted public records ranked by research state.
- **Output**: one closed JSON object = `research_state` update + `plan` of 1..12 actions; strict JSON schema at provider + local validation; runtime preconditions (location, ownership, empirical grounding, capacity, treatment permissions); invalid output → logged safe WAIT. Transport failures retried without advancing world time (17 of 89,617 calls, 0.019%).
- **Initial positions**: deterministic nested permutation of walkable cells (so N=50 positions are the first 50 of the N=200 positions). Macroturn phases staggered and matched across conditions.
- **The BioFoundry system prompt** is not printed in the paper; it is in `src/biofoundry/policies/llm.py` (`SYSTEM_PROMPT`). Verbatim:

> You are one homogeneous research agent in BioFoundry World.
> You have only local observations, bounded memory, and your own scientific knowledge.
> Collectively invent interacting bioinspired material systems for habitat resilience. No artifact catalog, biological analogy, or final design is supplied: identify needs and originate candidate mechanisms yourself. Do not invent observations or claim unmeasured effects.
>
> Return exactly one JSON object containing a private `research_state` update and a `plan` list of 1 to {max_plan_actions} actions that will execute over later microticks. A later macroturn can continue the work, so include only actions that remain valid without new evidence. The research state is your own notebook: preserve or revise your self-chosen goal, hypothesis, progress, next observable checkpoint, and collaboration need. Its text is not rewarded and does not change physics. Preserve up to sixteen stable evidence or program IDs in `evidence_ids`; these pointers let general retrieval learn which prior experience actually supports later actions.
> In recipes, list each material input once with its total mass and give one to four distinct design principles as short phrases; never repeat steps or text merely to fill an array. Every action must contain every legal key: verb, direction, resource, artifact, target_x, target_y, target_artifact_id, target_agent_id, reply_to, amount, message, insight, recipe, program, artifact_spec, causal_parents. Use direction "STAY", resource/artifact "NONE", amount 0, target coordinates -1, empty target IDs, reply_to, and message strings, null recipe/program/insight/artifact_spec, and an empty causal_parents list when a field is irrelevant. Enum names are supplied. Programs use the bounded straight-line Artifact Behavior DSL; never return Python, shell code, imports, network calls, or loops.
>
> The response schema is representational vocabulary, not evidence that a material, station, or affordance exists in this world. Base executable designs on your own empirical_knowledge. Unlisted materials remain uncertain rather than proven absent; form and revise your own beliefs from observations and action outcomes.
>
> **You are not assigned a role. If a public task board is visible, infer an unmet need, claim a useful task, and revise it when other agents' work or feedback warrants. Prefer actions that advance the complete scientific cycle over repetitive harvesting.**

  (bold mine). The user prompt additionally contains an `ACTION_MANUAL` (one bullet per verb, pruned to the verbs allowed in the condition), the observation packet, and a `recent_behavior_summary` ("a factual bounded-window count of your own attempts ... decide whether repetition remains informative"). AshenRealm prompt (`worlds/ashen_realms/prompts/agent_instructions.md`) is 6 lines: "You are a research and engineering agent in the Ashen Realms ... Survey terrain, extract rocks and ores, compare safe processing routes, and develop measured infrastructure ...".

### 1.4 Horizon
- 800-tick study: macroturn interval 50 → **16 LLM decisions per agent**; one queued action executes per tick.
- 3,200-tick study: **64 decisions per agent** (6,400 scheduled decisions per N=100 episode).
- Held-out assay: 288 physics ticks × 8 schedules, agents removed.
- Wall-clock: **not stated**. Provider calls for the full 48-episode 800-tick matrix: 89,617. Token consumption "reported separately" (not in the text I read).

### 1.5 What agents can do (complete verb menu, `types.py` `ActionType`)
WAIT, MOVE (one cardinal tile), INSPECT (private citable record of local site), HARVEST (≤0.30 mass of whatever is on tile), DEPOSIT (to shared depot at station), OPERATE (fabricate microbatch from recipe at station), TEST (reveals deterministic material properties of own latest microbatch), PROPOSE_RECIPE, BUILD (consumes recipe + `artifact_spec`), REPAIR, DISMANTLE, COMMUNICATE (local broadcast or addressed message), PUBLISH (append-only public archive record with ID), DEPOSIT_INSIGHT (spatial note readable by nearby agents even when communication disabled), WRITE_PROGRAM, FORK_PROGRAM (needs known parent id, changed instructions), CLAIM_TASK (writes to public task board), TEACH (transfers own retained records into another agent's durable notebook), TRADE (transfer resource to adjacent agent), COMBINE_DESIGN (recipe using materials grounded by ≥2 cited publications), METABOLIZE (optional treatment only). 21 verbs.

### 1.6 Communication channel
- Messages: local radius, broadcast or addressed; delivered at recipient's next macroturn (no extra model calls); stable IDs; `reply_to` and fulfillment IDs link requests to later actions.
- Public archive (PUBLISH), public task board (CLAIM_TASK), spatial insights, TEACH (durable, cites evidence IDs), TRADE, program observation/fork.
- Representative full-culture N=100 seed-3301 3,200-tick run: 2,914 delivered messages, 40 TEACH events, 52 trades, 457 program installations, 389 artifacts (Fig 17 counts 3,924 delivered-message *recipient* edges and 358 cross-artifact program-descent events).
- Epistemic vs physical contribution tracked separately; co-location alone does not count; citing cannot create matter.

### 1.7 Objective / reward
- There **is a mission**: "develop bioinspired material systems for environmental resilience" / "Collectively invent interacting bioinspired material systems for habitat resilience". No recipe, no catalog, no assigned roles.
- **No reward signal to agents**: evaluator equation hidden; no global score supplied; research-state text "not rewarded". Agents see only outcomes of their own admissible actions/tests (and, via TEACH/PUBLISH, others' recorded measurements).
- Observer-side endpoints (not seen by agents): discovery-frontier AUC, best final artifact, portfolio resilience, held-out resilience, validated inventions (gate: tested recipe + complete design + agent-authored program + performance threshold + behavioural-novelty threshold).

### 1.8 How "roles / states" are detected — three analyses

**(A) 800-tick whole-trajectory phenotypes (Fig 5).**
- Unit: one complete agent trajectory. 15 features, each robust-scaled. From `mobility_analysis.py` `BEHAVIOR_FEATURES` (name → paper label → transform):
  1. `distance_traveled` → path length (log1p)
  2. `net_displacement` → net displacement (log1p)
  3. `displacement_efficiency` → path directness (identity)
  4. `distinct_coarse_cells` → regions visited (log1p)
  5. `movement_snapshot_fraction` → mobile snapshots (identity)
  6. `artifact_contact_fraction` → artifact proximity (identity; within 3 cells of an active artifact)
  7. `artifact_bound_movement_fraction` → artifact-bound movement (identity)
  8. `moving_toward_artifact_fraction` → artifact-directed movement (identity)
  9. `encounter_exposure_per_snapshot` → nearby agents (log1p)
  10. `artifact_work_rate_per_100_ticks` → technology work (log1p)
  11. `social_interaction_rate_per_100_ticks` → social interaction (log1p)
  12. `observation_testing_rate_per_100_ticks` → observation/testing (log1p)
  13. `material_processing_rate_per_100_ticks` → material processing (log1p)
  14. `construction_control_rate_per_100_ticks` → construction/control (log1p)
  15. `culture_coordination_rate_per_100_ticks` → culture/coordination (log1p)
- Algorithm (code): log1p on flagged features → episode-balanced training subsample (equal rows per condition×N×seed episode, seeded RNG) → median imputation → drop zero-variance features → `RobustScaler(quantile_range=(5,95))` fit on training rows → clip to ±10 → `KMeans(n_init=32, random_state=1729)` for k = 2..6 → silhouette (sample_size 2,000) → **k = argmax silhouette** → predict all rows. PCA(2) is display only. Condition, population, seed, identity labels excluded from the feature matrix.
- Result: k=2: C1 "artifact-centered work" (artifact proximity, artifact-bound motion, construction/control, cultural coordination high), C2 "mobile exploration". At N=200 artifact-centered fraction ≈ **27% full culture, 20% no explicit culture, 17% no communication**. Fractions compared at seed level.

**(B) 3,200-tick physical-only phenotypes (Fig 16).**
- 800 trajectories from 8 shared-world episodes. **9 features**: "movement, coverage, artifact-proximity, artifact-directed-motion, and nearby-agent-exposure" — the exact list is not printed, but this matches features 1–9 above (the six per-100-tick rate features excluded). Communication, cultural actions, technology-work counts, condition labels excluded. k=2, silhouette 0.472.
- Result: artifact-centered fraction **52.8% full culture vs 31.0% no explicit culture**; paired difference 21.8 pp, seed-bootstrap 95% CI 12.0–33.5.

**(C) Temporal role states (§2.7, Fig S4).**
- Trajectories cut into non-overlapping **200-tick windows**; 22,400 agent-windows from 20 episodes (12 × N=200 800-tick under three shared conditions + 8 × N=100 3,200-tick under two conditions); deterministic episode-balanced sample of 16,000 windows for fitting.
- **13 features** ("movement, spatial-context, task-action, and cultural-interaction"); exact list **not stated** in paper and **not found** in the released `mobility_analysis.py`/`analysis.py`/`technology_ecology.py`/`trace_analysis.py`; presumably a per-window variant of the 15 above minus two. Labels withheld: condition, study, population, seed, identity, time.
- Hierarchical: k=2 broad modes (silhouette 0.467) then each parent split 2-way independently (conditional silhouettes 0.379 artifact-centered parent, 0.259 mobile parent), min 5% child occupancy. Four states: **R1 constructor/operator, R2 artifact-local caretaker, R3 cultural coordinator, R4 mobile surveyor.**
- Stability: leave-replicate-family-out adjusted Rand index 0.999 (broad split), 0.921 and 0.980 (conditional splits).
- Anti-circularity: refit with only 11 physical/task features (culture/coordination and social-contact removed) → 3 modes, silhouette 0.551 (mobile observation/testing; stationary artifact-proximal construction; artifact-local movement with material work).
- Succession: 800-tick N=200 full culture constructor fraction 0 → 0.240 (first → last window), coordinator 0.814 → 0.560. 3,200-tick N=100 full culture constructor 0.008 → 0.535, coordinator 0.695 → 0.292. No-explicit-culture ends constructor 0.252, mobile surveyor majority 0.633.
- Window-to-window state switching: full culture 0.270 vs no-explicit 0.102 (800-tick); 0.244 vs 0.138 (3,200-tick). Authors: "roles are not permanent social classes".
- **Null models for the clustering itself: none.** No shuffled-feature null, no isolated-agent clustering (independent-search members were assayed for endpoints but not clustered), no scripted-policy baseline (a `policies/scripted.py` exists in the repo but is not used as a differentiation control), no initial-position confound check. Only silhouette + leave-replicate-out ARI. Null models are used elsewhere: hypergeometric degree-conditioned null + Benjamini–Hochberg q≤0.05 for agent–agent and artifact–artifact projections; 200 timestamp-shuffled replicates for the creator→adopter motif; 64 random removal orders for robustness.
- AshenRealm check (Fig S6): 15 features, N=50, seeds 1702–1705, three modes (artifact-centered, mobile exploration, stationary/low-activity); PC1/PC2 33.1%/20.2%.

### 1.15 My critique
1. **Differentiation is largely induced by the action menu and the mission.** The 21-verb schema pre-partitions behaviour into locomotion/observation vs fabrication/build/program vs communicate/teach/claim. Ten of the fifteen clustering features are per-100-tick rates of these verb categories or derived spatial statistics of artifact proximity. Clustering rate-vectors over a schema will always find "explorers" (many MOVE/INSPECT) vs "builders" (many BUILD/WRITE_PROGRAM). The paper's own anti-circularity check only removes the two culture features; it does not test whether a policy with no social information (isolated agents, or the repo's scripted policy) produces the same two clusters. The independent-search members received identical schedules and positions — clustering them was cheap and was not done. That is the single most damaging omission: if isolated agents also split 30/70 into artifact-centred vs mobile, "self-organized differentiation" is a property of the task workflow, not of the society.
2. **The prompt instructs specialisation.** "You are not assigned a role" is immediately followed by "infer an unmet need, claim a useful task, and revise it when other agents' work or feedback warrants" and "Prefer actions that advance the complete scientific cycle over repetitive harvesting", plus a `recent_behavior_summary` nudging against repetition and a public task board. A reviewer will say the society was told to divide labour. The mission ("Collectively invent ... for habitat resilience") is also a shared objective — the environment is task-bearing even if reward-free.
3. **"Initially identical" is only prompt-identical.** Temperature 0.7 sampling, deterministic but distinct starting cells, and immediately divergent local observations make agents heterogeneous from tick 1. A trivial confound: agents seeded near a foundry/resource biome become builders; agents seeded far away become surveyors. No test relates phenotype to initial position or distance-to-station. This is the confound I would attack first.
4. **"Roles" = action-frequency clusters with a moderate silhouette (0.47) and high fluidity.** k chosen by silhouette over 2..6 with k-means always returns a partition; 0.47 is unremarkable for a 15-D rate space. Window-to-window switching of 0.27 means a quarter of agents change "role" every 200 ticks; the "succession" (coordinator 0.81 → 0.56, constructor 0 → 0.24) reads as a population-wide phase change (everyone surveys first, then builds once materials exist) rather than a division of labour. The discriminating statistic — within-window state entropy (are different agents in different states at the same time?) — is not reported. Their honest framing "dynamic states rather than fixed identities" already concedes this.
5. **Seeds n=4, minimum attainable p=0.125.** Every differentiation contrast (27/20/17%; 52.8 vs 31.0) is descriptive. A reviewer at an ML venue will treat this as a demonstration, not an experiment.
6. **Single model (gpt-5.6-luna, low reasoning), single prompt, single temperature; no model ablation.** Whether a different model differentiates at all is unknown.
7. **The cultural-coordinator state is partly definitional** (they admit it), and full culture's larger artifact-centred fraction may just be that COMMUNICATE/TEACH/CLAIM_TASK verbs exist and are counted in the features that define C1.
8. **Overclaiming vocabulary**: "technological evolution", "culture", "invention", "society", "civilisation-adjacent" framing over what is a deterministic game with a hidden scoring function. The strongest and most defensible results are the mechanism ones (95% of adoption via observation; isolated search wins the single best artifact; no universal cultural crossover), not the role claim.
9. What a reviewer would ask for: isolated-agent clustering null; initial-position covariate; within-time-window role entropy; a second model; k-sensitivity; a permutation null on silhouette; wall-clock and token accounting; and removal of the "claim a useful task" instruction.

## 2. Physics of Agents: Statistical Mechanics Predicts Collective Behavior of AI Agents (arXiv 2608.16578)

- Authors: Batu El, Jinhee Paeng, Fatih Dinc, Shiye Su, Mete Erdogan, Aneesh Pappu, Haotian Ye, Wanjia Zhao, Surya Ganguli, James Zou (Stanford). v1 17 Aug 2026, CC BY 4.0. Venue not stated. Code github.com/batu-el/physics-of-agents; data huggingface.co/physics-of-agents; online appendix.
- **Setup**: N=32 agents per community; T=8 synchronous rounds (also an asynchronous variant, 0.5 updates/round/agent); K=5 votes per agent per round averaged to ō ∈ {−1,−0.6,…,1}; state s=sign(ō). Each agent has a **fixed distinct persona** (agents are heterogeneous by construction): subjective = TWIN-2K-500 human profiles rendered as text by gpt-4o-mini; objective = a worked MATH solution as "expertise". Questions: 40 MATH problems binarised with a Claude-4.8-Opus distractor; 20 political statements (Promptfoo dataset); **questions pre-filtered for high answer entropy** ("necessary for observing interesting dynamics"). Signed communication graph J ∈ {−1,0,+1}^{N×N}, symmetric, fixed; families: random signed, square lattice, triangular lattice, low-rank with frustration γ∈{0,0.1,0.2}. Messages: two sentences, routed to "sources you tend to agree with" / "disagree with" inboxes; Markovian (inbox refreshed each round). Opinion prompt forbids reasoning ("gut answer ... single character"). Models: GPT-4o-mini, Gemma-3n-E4B-it, Qwen3.5-9B, Llama-3.1-8B-Instruct. n = 9,600 communities in the main analysis (4 models × 60 questions × 10 graphs × 4 episodes); >10,000 with OOD and async experiments. Wall-clock not stated.
- **Regime split**: three "characteristic regimes" defined on (net opinion n(t), conviction c(t)=mean ō²): consensus (high |n|, high c), polarization (|n|≈0, high c), indifference (both ≈0). **Thresholds are quantile-based**: c* = lower tertile of conviction pooled over all rounds; n* = median |n| among committed communities (Table S3, e.g. GPT-4o-mini objective c*=0.910, n*=0.475). So the three regimes are equal-sized by construction over the pooled data; what is empirical is the **temporal flow**: early rounds dominated by indifference, indifference falls and consensus rises monotonically with rounds. The split is therefore not "spontaneous" in the sense of a discovered partition; the finding is that conviction builds and communities move from indifference to ordered states.
- **Archetypes**: individual by number of sign switches (Frozen 0, Switcher 1, Intermittent 2, Oscillator >2) — frozen dominates, then oscillators. Group by initial/final net opinion with split band δ=0.2: Persistent Split, Convergence, Divergence, Majority Switch, Persistent Majority; Divergence+Majority Switch reach 11–12% for GPT-4o-mini and Qwen3.5-9B. Four rare non-monotone types (Backtrack, Recovery, Hesitation, Flipping). Episodes with identical persona/graph/question frequently disagree on archetype (Fig S11) — so the fitted model is evaluated at the distribution level.
- **Ising fit**: energy E = −½ Σ J_ij s_i s_j − Σ g_i s_i; Glauber-type logistic update P(s_i=+1)=σ(β Σ J_ij s_j + g_i); three couplings β⁺ (concordant), β⁻ (discordant), β₀ (any tie); g_i = wᵀφ_i with φ_i = [1 | PCA-3 persona emb | PCA-3 question emb | outer product] ∈ R¹⁶ (text-embedding-3-small). Fit by full-batch Adam, cross-entropy on one-step transitions, two-stage (β₀ first). Fitted couplings (Table 3, three-coupling, objective/subjective): GPT-4o-mini β⁺ 2.10/2.39, β⁻ 0.75/1.08, β₀ 0.93/0.61; Gemma 0.29/0.44, 0.23/0.35, 0.96/0.55; Qwen 0.90/1.12, 0.50/0.65, 1.01/0.64; Llama 0.97/1.35, 0.61/0.67, 0.97/0.99. Effective concordant weight β⁺+β₀ = 0.99–3.03; effective discordant β₀−β⁻ ≤ 0.73, negative for GPT-4o-mini subjective (−0.47) and ≈0 for Qwen subjective (−0.01) → attraction dominates, favouring consensus over polarisation. Five-coupling (truth-split) rule: β⁺_T > β⁺_F and β⁻_F > β⁻_T in all four models → truth-seeking.
- **Prediction**: balanced accuracy (flip/stay × label) on held-out questions: three-coupling discrete rule 75–86 one-step, 61–77 rollout, best in every cell of Table 1; in-/out-of-distribution graph gap ≤2.4 points; unseen graph families 85.0–97.8 one-step, 59.7–89.3 rollout (Table 2). Baselines: Persistence 50 (balanced), Interaction-free ~chance (59–61 for Gemma), Mean-field (Curie–Weiss) mid-50s to low-70s. Archetype-share reproduction: MAD ≈3 points objective, ≈5 subjective; largest single gap ≈10 (Qwen subjective Persistent Majority); model over-produces oscillators.
- **Critical temperature**: rollouts of fitted rule at 41 log-spaced T ∈ [0.05, 20], 500 steps (last 300 kept), χ = N·Var_t|n(t)| peaks at T_c; fitted operating point T=1 lies **below T_c in every model–dataset cell** → ordered regime → conviction buildup.
- **Political drift**: fraction of right-leaning communities Gemma 75%→96%, Qwen 52%→67%, GPT-4o-mini 30%→37%, Llama ≈53% flat; left→right switches outnumber right→left 23:1, 33:18, 8:3 (%). Label bias: Llama +1 fraction 39%→16% on label-balanced objective set.
- **Limitations (stated)**: single binary question; fixed symmetric J; Markovian inbox (no history); message content discarded by the model; persona-conditioned agents are not humans. Future: Potts/vector opinions, dynamic J, spatial proximity, memory, Moltbook data, heterogeneous model populations, larger N. **Unstated**: high-entropy question filtering is a selection on the dependent variable; personas make agents heterogeneous, so nothing here is about identical agents; 8 rounds; no persistent artifacts; no differentiation of *behaviour*, only of opinion.
- Relevance to us: this is a **homogenisation** result (below T_c, consensus) on short-horizon chat, and the "archetypes" are trajectory-shape bins, not roles. Useful as the published "chat collapses to order/consensus" contrast and as a template for a fitted low-dimensional dynamical model.

## 3. Multi-Agent Teams Hold Experts Back (arXiv 2602.01011, v4 28 May 2026)

- Authors: Aneesh Pappu, Batu El (Stanford), Hancheng Cao (Emory Goizueta), Carmelo di Nolfo, Yanchao Sun, Meng Cao (Apple), James Zou. Code github.com/apappu97/multi-agent-teams-hold-experts-back. Venue not stated (v4; ICML-style Impact Statement).
- **Setup**: teams of **4 agents, 4 discussion rounds**, randomized speaking order, growing shared context, final answer = majority vote of post-discussion individual answers. **No roles, no topology, no workflow** ("self-organizing", "equal-status"). Tasks: NASA Moon Survival, Lost at Sea (rank 15 items, L1 error), Student Body President (hidden-profile, rank 4 candidates); MMLU-Pro, GPQA Diamond, SimpleQA, HLE text-only, MATH-500 (100 problems each). Models: psychology tasks Claude 3.5 Haiku / GPT-4o-mini in 4+0, 2+2, 0+4 compositions; ML benchmarks task-specific teams from Claude Opus 4/4.5, Sonnet 4.5, Haiku 3/3.5/4.5, GPT-5, GPT-4o, GPT-4o-mini, GPT-3.5T, o3-mini, o4-mini (heterogeneous by design). Expertise induced by giving one agent (concentrated) or partitioning across agents (distributed) the ground-truth reasoning. Conditions: No Information, Expert Not Mentioned, Reveal Expert (GEPA-optimised deference prompts), Best Individual, Full Information. 30 seeds per cell (psych), 10 seeds per config × condition in Fig 2, 3 seeds for adversarial/full-info.
- **The null / negative result**: teams never reach strong synergy (≥ best member). Relative synergy gap (% error increase over expert), Table 1: NASA 78.7±11.6 (ENM) / 81.8±12.9 (RE) concentrated, 113.4 / 110.1 distributed; Lost at Sea 55.6 / 58.6, 50.1 / 42.1; SBP 98.7 / 73.5, 66.0 / 17.3. Absolute: NASA team 25.08 vs expert 15.03; reveal 25.35 vs 14.76. ML benchmarks (Table 2), relative gap vs At-Least-One-Correct: MMLU-Pro 6.3%, GPQA 14.4%, SimpleQA 18.1%, HLE 41.1%, MATH-500 20.3%; Team(ENM) 86/76/51/28/63 vs Best Individual 86.5/78/52/29/73.5 vs ALOC 91.8/88.8/62.3/47.5/79.0. Debate, opt-out, CoT+MV all below ALOC. Revealing the expert barely helps → **leveraging, not identification, is the bottleneck**. Full-Information ablation: 4 experts ≈ 1 expert (16.22 vs 15.03), so the loss is expertise asymmetry, not communication noise. Team-size dilution: r between size and synergy gap 0.32–0.59 (all p<.05), persists under Reveal Expert. Adversarial saboteur: minimal degradation. Conversational coding (Gemini 3.0 Pro, 94% agreement with humans on 50): integrative compromise correlates with gap (NASA r=.55, SBP r=.69), epistemic deference negatively (NASA −.44, SBP −.68), expert flexibility positively (.58, .61); Lost at Sea non-significant. Weak synergy (≥ member average) is achieved everywhere.
- **What it is and is not**: the paper does not measure "role emergence" directly; it measures whether an equal-status group *functionally* self-organises around its expert. The answer is no: the group averages. There is no leader, no deference hierarchy, no spontaneous division of epistemic labour even when told who the expert is. That is the published null on self-organisation in short-horizon chat.
- **Limitations (stated)**: alignment attribution is correlational; small task set. **Unstated**: 4 rounds only; task-bound with a single correct answer (no room for differentiation to pay off); no persistence; majority vote aggregation structurally rewards averaging; heterogeneous models, so the null is not about identical agents.

## 4. Kandoussi 2604.00026 (abstract only, for §5e)
"Who Am I, and Who Else Is Here?" Behavioral Differentiation Without Role Assignment in Multi-Agent LLM Systems. Houssam EL Kandoussi, 11 Mar 2026. 7 heterogeneous LLMs on one inference backend, 12 series, 208 runs, 13,786 messages coded on six behavioural flags by two LLM judges (κ=0.78; human κ=0.73 on 609). Findings: heterogeneous groups differentiate more than homogeneous (profile cosine similarity **0.56 vs 0.85**, p<1e-5, r=0.70); compensatory responses when an agent crashes; revealing real model names raises convergence (0.56→0.77); **removing all prompt scaffolding collapses profiles to homogeneous-level similarity**; behaviours absent in isolation. ## 5. Synthesis for our paper (36 agents, 43 h, no task, no reward, real shared filesystem + board + citations; 4–5 isolated replicate machines, ~10k artifacts)

### (a) What SwarmWorld already establishes — not claimable as new
1. Prompt-identical LLM agents with no assigned roles, in a shared persistent world, separate into distinguishable behavioural phenotypes under label-blind clustering (2 modes; 4 dynamic states).
2. Those states are fluid, agents switch, and the population shows a temporal succession (survey/coordinate early → construct late) as the environment matures.
3. Agents build on each other's persistent artifacts: near-universal non-creator reuse, multi-author artifacts, content-addressed fork lineages up to depth ~10–12, attributable provenance graphs.
4. Transmission is mostly stigmergic: ~95% of first reuse via encountering the artifact, not via a message from the creator; direct creator→adopter contact not enriched over a shuffled null.
5. Explicit communication changes *organisation* (more artifact-centred agents, more ties, more forks, localisation) but not every functional endpoint; the shared substrate alone supports a capable society.
6. Modular, persistent agent–artifact networks with few hubs; robust to random loss, fragile to targeted loss.
7. Long horizon (3,200 ticks, 64 decisions/agent) with checkpointed crossover analysis.
8. Recurrence of the phenotypes in a second world (AshenRealm).
9. A reproducibility standard (seeded worlds, replayable traces, hashed manifests, released data) that a reviewer will hold us to.
So: "homogeneous LLM agents self-organise into roles without being told to" is, as of 26 Aug 2026, a published claim, with a materials-science framing and a Buehler-lab pedigree. We must cite it as the closest neighbour and position against it, not claim priority.

### (b) What our data adds that SwarmWorld lacks
1. **No mission, no task board, no instruction to specialise.** SwarmWorld's prompt says "Collectively invent ... identify needs ... claim a useful task ... prefer actions that advance the complete scientific cycle". If our agents differentiate with zero objective, that removes SwarmWorld's biggest confound (critique §1.15 items 1–2). This is the headline contrast; quote their prompt line verbatim in related work.
2. **Open action space.** Their agents choose among 21 schema verbs; ours act through a shell/filesystem with no verb menu. Differentiation over a fixed verb menu can be a property of the menu; differentiation over unconstrained actions cannot. Our feature set must therefore be *derived post hoc from artifact types the agents themselves created* (findings/tools/challenges/builds), which is a stronger test.
3. **Real artifacts, externally verifiable.** Their artifact function is a hidden game-level scoring surrogate ("not SI-calibrated"). Ours are real files: tools that run or don't, claims that check out or don't. We can measure *correctness*, not just simulator score.
4. **Verification as a social act.** SwarmWorld has TEST (own microbatch only) and vignettes of agents re-measuring others' claims, but no quantitative treatment of agents checking each other. If we have verification acts (reproducing, refuting, confirming others' findings), that is an epistemic-institution result they do not have.
5. **Institutions.** Their task board, archive, citation field (`causal_parents`) and teaching channel are all *engine-supplied*. If our agents *invented* boards, norms, citation conventions, review, or naming rules, that is emergent institutional structure vs. supplied infrastructure. Must be careful: our board is supplied too; what counts is what agents built on top of it.
6. **Cross-machine replication.** Their replication is 4 seeds of one simulator on one model. Our 4–5 isolated machines (~10k artifacts) are independent societies; if the same state vocabulary appears on every machine (leave-machine-out ARI, as they do leave-replicate-out), that is a stronger replication claim, and machine becomes the unit of inference exactly as seed is theirs.
7. **Reflexivity.** Agents reading the orchestration source is absent in SwarmWorld (agents cannot see the engine). Whether that changes behaviour (e.g. agents modelling the scheduler, gaming it, documenting it) is new.
8. **Wall-clock / asynchronous cadence.** 43 h of agent-driven timing vs. a fixed macroturn schedule with 16–64 decisions per agent. Report our decisions-per-agent so the horizons are comparable; if ours is >64, say so.
9. **Citations among agents** as a native behaviour rather than a schema field — a citation graph we can analyse with their own network toolkit (Louvain, hypergeometric-null projections, nestedness, participation).
10. Weaknesses we share and cannot claim over them: single model (if so), no reward, few replicates, LLM-coded behaviour. Their 4-seed, min-p 0.125 stance ("effect magnitude, paired consistency, mechanism") is a framing we can adopt verbatim and cite.

### (c) SwarmWorld's differentiation operationalisation, step by step, and the mapping to our data

Per-agent (whole-run) phenotype pipeline:
1. Build one row per agent with 15 features (list in §1.8A). Movement/space features: path length, net displacement, directness (=net/path), regions visited, fraction of snapshots moving, fraction of snapshots within 3 cells of an artifact, fraction of movement that is artifact-bound, fraction of moves toward an artifact, mean nearby agents per snapshot. Activity-rate features per 100 ticks: technology work, social interaction, observation/testing, material processing, construction/control, culture/coordination.
2. log1p on count/rate/length features; identity on fractions.
3. Episode-balanced training subsample (equal agents per condition×N×seed).
4. Median-impute; drop zero-variance features.
5. `RobustScaler(quantile_range=(5,95))` fit on training rows; clip ±10.
6. k-means (`n_init=32`, fixed seed) for k=2..6; choose k by silhouette (2,000-row sample). Predict labels for all rows.
7. Report cluster-mean standardised signatures (heatmap), PCA(2) for display only, seed-level (not agent-level) cluster fractions per condition, paired seed-bootstrap CI (20,000 resamples).
8. Robustness: refit without communication/culture features (anti-circularity); leave-replicate-family-out adjusted Rand index.

Temporal-state pipeline:
9. Cut each trajectory into non-overlapping windows (200 ticks = 4 macroturns); compute the 13 per-window features (unlisted; use the per-window analogues of 1–15).
10. Same scaling; hierarchical k-means: 2 broad modes, then each split independently in 2 with ≥5% child occupancy; silhouettes at each level.
11. Report: state fractions per window (succession curves), window-to-window switching rate, leave-replicate-out ARI, physical-only refit.

Our analogue (proposal):
| SwarmWorld feature | Our filesystem analogue |
|---|---|
| path length / net displacement / directness | number of distinct directories touched; depth of directory traversal; ratio of unique to total paths |
| regions visited | distinct top-level project areas touched |
| mobile snapshots | fraction of agent turns with a read of a file not previously read |
| artifact proximity / artifact-bound movement / moving toward artifact | fraction of turns operating on an existing artifact (read/edit/cite) vs creating new; fraction of edits on files authored by others |
| nearby agents | number of distinct other agents whose files were touched in the window |
| technology work | tool/build files written or executed |
| observation/testing | reads + verification runs (executing others' tools, re-deriving findings) |
| material processing | edits to existing artifacts |
| construction/control | new findings/builds authored |
| social interaction | board posts, replies, mentions |
| culture/coordination | citations made, challenges posted, norms/announcements |
Window = fixed wall-clock (e.g. 1 h ⇒ 43 windows) or fixed turn count; report both. Unit of inference = machine. Run k=2..6 with silhouette; hierarchical split; leave-machine-out ARI; artifact-type-free refit (drop board/citation features) as the anti-circularity control.

### (d) Their controls we must reproduce (and the two they skipped that we must add)
Reproduce: (1) label-blind clustering — no machine/agent/time labels in the feature matrix; (2) k selected by silhouette across a range, reported; (3) PCA/UMAP display only, clustering in full space; (4) episode(machine)-balanced fitting; (5) leave-machine-out ARI stability; (6) anti-circularity refit with communication/citation features removed; (7) machine-level fractions with paired bootstrap, no agent-level p-values; (8) switching rate and succession curves, so we cannot be accused of claiming fixed identities they already refuted; (9) content-addressed provenance for reuse claims (hash of artifacts; who read/edited what, when) and a timestamp-shuffled null for creator→adopter contact; (10) hypergeometric degree-conditioned null + BH for any agent–agent co-use projection.
Add (their gaps, which a reviewer will now demand of both papers): (11) **single-agent null** — run 1-agent instances with the same prompt and horizon; cluster their windows with the society model; if the same states appear, differentiation is workflow, not social; (12) **permutation null on silhouette** — shuffle features within column across agents, recompute best silhouette, report the percentile of the observed value; (13) **initial-condition covariate** — we have no geography, but we have start time / first file seen / first board post read; regress state on these; (14) **within-window state entropy** — show that at the same time different agents occupy different states (division of labour) rather than the whole population moving together (phase); (15) if feasible, a second model.

### (e) The published-null contrast a positive long-horizon result would overturn
- **Experts Held Back**: 4 heterogeneous agents, 4 rounds, chat, task-bound, majority vote → no self-organisation around expertise; agents average; larger teams average more; deference prompt cannot fix it.
- **Kandoussi**: 7 LLMs, chat; homogeneous groups do not differentiate (cosine 0.85); differentiation requires architectural heterogeneity *plus* prompt scaffolding; strip scaffolding and even heterogeneous groups collapse; isolation shows nothing.
- **Physics of Agents**: 32 persona-heterogeneous agents, 8 rounds, chat; the dynamics run below the critical temperature and drive toward consensus (attraction β⁺+β₀ ≫ repulsion); the only "archetypes" are opinion-switch counts, and heterogeneity is imposed by persona.
Common structure of the nulls: short horizon (≤8 rounds), pure chat, no persistent external substrate, a single shared question or task, aggregation by vote/consensus. Under those conditions identical (or even different) models converge. SwarmWorld is the positive case but with a simulator, a mission, a task board, an instruction to claim tasks, and a verb menu — every one of which a sceptic can name as the cause. Our result, if it holds, is the clean cell in the 2×2: **no task + no role + no menu + long horizon + persistent real artifacts ⇒ differentiation**. The claim to write is therefore not "LLM agents differentiate" (SwarmWorld owns that) but: *the published convergence results are properties of short-horizon, substrate-free, task-bound chat; give identical agents a persistent shared substrate, time, and nothing to optimise, and they differentiate anyway, with the differentiation carried by artifacts rather than messages* — the last clause is where SwarmWorld's 95%-via-observation finding becomes an ally rather than a competitor. Two cautions: Kandoussi's "no scaffolding → convergence" cuts against us unless our prompt is documented as scaffold-free; and Experts Held Back's dilution-with-size result predicts that 36 agents should homogenise more, so a positive result at N=36 is a direct reversal worth stating in those terms.
