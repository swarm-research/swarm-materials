### ⚠ 数据质量：引用记录含 15.7% 占位数据

1,711 条引用中有 **268 条（15.7%）指向 `test/path.py`、`some/file.py` 这类不存在的占位路径**，是 agent 学习使用引用工具时留下的。

**任何基于引用的分析都必须先过滤**，判据是 `file` 字段以 `commons/` 或 `agents/` 开头。过滤后有效引用 1,443 条。

这批噪声有实际后果：淘汰机制按引用数判定存活，agent-099 和 agent-901 **完全依靠占位引用获得存活分**；agent-022 的引用中 44.6% 是占位数据。

## 03_analysis — 分析材料

| 文件 | 说明 |
|---|---|

| `swarm_cost_rows.json` | 每会话的模型、轮数、估算输入输出 |

### 主要结论

**分工**：36 个 agent 中 8 个（22%）产出结构显著偏离群体基线（KL≥0.3）。平均熵 1.69 / 上限 2.32——出现了倾向性分工，但没有排他性专精，通用能力未丧失。

**网络结构**：被引 Gini 0.361，37 个 agent 仅 1 个零被引，**互引率 53.0%**。形成的是大面积互惠网络而非等级制。

**引用依据**：跟随质量而非数量——agent-021 用 31 件产出获得 110 次引用（3.55 次/件），而 57 件产出的 agent-016 只有 0.88 次/件。文件大小与被引无关。

**各类产出被引率**：challenges 70.0% > tools 45.8% ≈ findings 45.7% > data 18.8% > builds 11.1%。提出问题的回报最高但产量最低（仅 30 件）；二次创作几乎无人再引用，累积只到第二层就中断。

**时间演化**：结构在第 2 时段（约实验前 1/3）达峰后衰减——引用量下降 83%，互引率一度归零，活跃者从 38 降至 18。**延长运行时间没有换来更多结构。**

**种子机制**：3 个被私下要求主动引用他人的 agent，产出仅高 14%，被引却高 94%。优势来自触发互惠回报，不是靠多产。

**对抗实验失败**：6 个卧底 agent 仅 1 个（agent-042 Saboteur）留下痕迹，且被引 0、产出 4 件，未造成可测影响。二代的 6 个未启动。**此部分数据不足以支撑结论。**
