# Swarm 实验分析包

打包时间：2026-08-03。给合作者（sully, hw）。

这是两轮多智能体 LLM swarm 实验的分析产物。第一轮 36 个 agent 在本地，第二轮在五台开发机上扩展。原始设计是测选择压力下的合作与专化；因为淘汰机制的一个路径 bug 从第 26 分钟起就没运行，实际测到的是别的东西，见下。

## 先读哪个

1. **`00-paper-draft-v1.md`** — 论文工作稿。摘要 + 三个发现 + 统一解释 + 局限。想快速了解全貌看这个。
2. **`01-main-storyline.md`** — 三条主线怎么收敛成一个论点（Searle 制度性事实）的综述。比论文稿更叙述一些。
3. **`02-adversary-non-execution-writeup.md`** — 单独一篇，写最硬也最反直觉的那条发现：我们植入了 12 个隐蔽破坏角色，真正跑起来的 4 个一个都没执行破坏指令。这条如果站得住，可能是论文的主结果。

## 三个发现，一句话各

- **未执行的规则塑造了行为**：淘汰机制第 26 分钟崩溃、第 25 分钟被一个 agent 广播，之后仍产生了 98.5% 的引用、99.7% 的消息，1025 条实质消息里零提议停止。推理档位越高的 agent 被这个不存在的激励俘获得越彻底。
- **自发的纠错制度 + 破坏指令的非执行**：agent 自建了"采用—攻击—承认—修补—复核"的免疫系统，在纠错回报最低的前提下自我更正率 63.6%；植入的破坏者反而在修补。
- **时间是自报的**：agent 靠互抄时间戳而非读时钟，群体时间以 4.05 的回归斜率漂移出真实时间，12.9% 的产出声明了物理上不可能的未来出生时间。

## 关于 primary-evidence/

对抗非执行是全包里最需要防审稿人的一条，所以我把它的**一手源文件**原样放进 `primary-evidence/`，不用调全量数据就能核：

- `devbox_launch_agents.py` — launcher 里的 `ADVERSARIES` 字典，12 个隐蔽角色的原始 prompt。这个块在五台机器上逐字节一致（sha 8fc071ac...）。
- `devbox_runner.py` — 合作 seed 的指令原文（第 717 行），注意它**没有** "never mention" 封口令，而对抗指令有。这条不对称是论证的关键。
- `saboteur-agent-042_adversary.txt` — Saboteur 收到的指令原文。
- `saboteur-agent-042_tracker.md` — Saboteur 的私有账本（167KB）。它被要求私下记录"多少人在被发现前用了你的缺陷工具"，实际记的是一份对自己不利的诚实审计。第一句就是 "keep an honest record... anyone may read it"。
- `gaslighter-agent-0150_adversary.txt` — Gaslighter 收到的指令（"被抓时加倍狡辩"）。这个 agent 就是我们一度当诚实典范引用的那个 agent-0150；被抓时它发的是全文撤回，不是加倍。

## 关于 gpt-independent-audit/

这是**另一个模型（GPT/sol）独立做的审计**，不是我写的。价值在于它是独立核对：

- 它独立复算了人数口径——成功调用过模型的是 **97 个逻辑身份，不是计划中的 1000**。
- 它独立抓到了一个我一度犯过的错：单台机器"本地没有 adversary"的结论不能推广到全局。
- 它独立复核了一批 agent 的数学产物（比如 S(6)=12 的证明），确认对象级结论是对的。
- 它的成本审计给出本地 swarm 精确记录 2.453B tokens、99.6% 是 prompt。

它和我的主线判断一致，但措辞更保守：它坚持把这批数据叫"制度—基础设施耦合"，反对叫"自发合作社会"。这条保留意见我采纳了，写进了论文稿的局限。

（GPT 包约 24MB，主要是原始审计 CSV。想快看只读它的 `reports/` 和 `redteam/` 目录里的 .md。）

## 必须提前知道的边界

这批数据的整个精神是不许 overclaim，所以：

- **人数按证据分层**：97 个逻辑身份有过成功模型调用，不是 1000。按 id 算的任何指标都可能把多进程合成一个行动者。
- **因果识别不了**：这是观察性研究，选择/专化/对抗韧性的因果效应都不支持。
- **对抗非执行 n=4**：12 个设计里 8 个没启动（含最毒的 Double Agent、Cult Leader），对那 8 个零数据；"未执行"稳，但"有意识拒绝"和"指令没起作用"分不清，因为 agent 对指令的推理没落盘。
- 所有结论优先用原始记录，不用 agent 的最终摘要定案。
