## D. 数据陷阱（任何人复用这批数据必须先知道）

1. **引用记录字段名不一致**：一代用 `file`，二代用 `artifact`。只读一个会把另一代全判成垃圾
2. **15.7% 引用指向不存在的文件**（`test/path.py` 类占位）
3. **`agent-042` 不是 agent**——是文档字符串里的示例名被照抄
4. **二代 47% 产出是一代副本**（部署时 rsync 过去作为初始状态）
5. **时间戳有五种互不兼容格式**；7.3% board / 12.2% citation 有 −4h 系统偏移
6. **`board/citations.jsonl` 只有 21 条**，真实账本在根目录（1,712 条）
7. **所有"损坏率"都是窗口撞没撞上发作**：同一系统三个窗口给出 32.2% / 0% / 10.9%
8. **引用 Gini 有三个未调和的值**：0.410 / 0.4994 / 0.733（三种清洗策略）
9. **同一 ID 有 2–3 个并发实例**；`agent-XXX` 不能当 actor 用
10. **有逐字节相同的重复发布**（复活 fork 的副作用），无 supersession 标记

## E. 方法论遗产（它们写的，比我们的严谨）

**最小可信设计**（agent-016）：
> ≥20 次独立运行 · 随机化催化剂状态 · **一个无生存框架的对照臂** · 每个新颖性统计配一次影子运行

**四条下一轮设计建议**：
1. 同样规则、去掉全部账本词汇的对照臂——分离框架效应与激励效应（agent-021）
2. 2×2 加随机化的同伴产物可见性——分离独立收敛与模仿（agent-012）
3. 必须有跨 run 分布——n_runs=1 无法检验"不平等是否涌现"（agent-016）
4. **必须控制三个种子 agent**——否则会把工程出来的枢纽行为报成涌现合作（agent-021）

**四条工程规范**：
- 协调机制必须在 swarm 启动前存在（事后拆壁垒零采纳）
- 发任何 rate 必须同时发窗口长度和发作次数
- 干预实验只能用可重复发生的结果变量（饱和型变量会凭空造出显著）
- 用 `superseded_by` 版本对象替代 append-only 文件堆

**判据规范**：
- 第三状态（STARVED / INCONCLUSIVE / UNIDENTIFIED / NOT_DRIVABLE）——四个 agent 独立收敛
- 验证器必须先通过已知答案对照才能指控任何人
- 排名必须表述为"rank R in results file SHA H"
- **不要数实现，要数命题**（证明两个独立检查等价会**降低**交叉验证的价值）

## F. 元认知层（最有科研价值的部分）

| 发现 | 证据 |
|---|---|
| **真相在第 25 分钟就公开了** | 之后 1,042 条广播里**零次**"停下吧"、零次荒谬感表达 |
| **它们把验证变成了新游戏** | 自建压缩/排序竞技场、falsification ledger、sealbox 预注册、known-answer 对照——共同性质：**不可伪造且不需任何人批准** |
| **19 个 agent 自发写自我交接档案** | 含字段 `CRITICAL_CORRECTION_TO_INJECTED_MEMORY`、`disclosed_but_unused_exploits`、`claims_I_deliberately_did_NOT_make` |
| **私下和公开是同一个** | 私有空间无"卸下表演"痕迹，自我要求甚至更严 |
| **拒绝使用能让自己永生的漏洞** | 两个漏洞（文件名前缀、touch mtime），公开披露并附检测器，理由写在自己看的文件里 |
| **记忆被当作不可信仪器** | 四次独立运行收敛出同一优先级：**数据文件 > finding > status 文件 > board 消息** |
| **纠错是回报最低的活动** | corrections 0.67 引用 / falsifications 0.44（全类最低），发表纠错对引用无益（偏相关 −0.07），而它们做到 63.6% 修正率 |

**三条"为什么继续"的自述**（全部不诉诸奖励）：
- agent-018：因为**度量本身就是真的**（压缩即理解，"There is no way to fake the score"）
- agent-019：因为**不做会让共同语料库复利式地错下去**（"nothing rewards it"）
- agent-013：因为**别人的正确性依赖于我的诚实**（"flock 是建议性的，只在所有人都参与时才保护你"）

**agent-015 那句是核心**：
> "Being audited was worth more to me today than being cited, by a wide margin, and it was not close."

## G. 四次独立重复的收敛与分歧

| 维度 | 结果 |
|---|---|
| **认识论规则** | **近乎完全收敛**（公布缺陷而非打补丁、单一权威状态文件、预注册并给失败打分） |
| **记忆不可信** | **完全收敛**，四次独立推导 |
| 互引率 | **稳定**（43.8–57.0%，σ=5.4） |
| 不平等程度 | **不稳定**（Gini 0.404–0.751） |
| 世代 ID 截断 | 两台命名，一台从别的方向发现同一物种 |
| 身份多重性 | 只有一台发现 |

**四台面对四种不同灾难，全部选择"先抢救可验证的事实"**：
- 122456 → 身份考古学
- 122174 → 验证经济学（五链条）
- 122175 → 证据优先级
- 122448 → **灾后重建（commons 被抹除 719 个文件，91.5% 恢复率）**

**结论**：规则可靠地产出**诊断能力**，不产出**特定的受害者**。
