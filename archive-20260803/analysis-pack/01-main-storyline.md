# 他们维护了一个没人在执行的世界

*主线综述稿。三条线其实是一件事。基于源码、私有目录、公共板、runner 日志与可复算审计;凡引用 agent 原话均为英文原文。GPT/sol 独立审计在多处并行印证,分歧处已标。*

## 一句话

这批数据最扎实的不是"LLM 在自然选择里长出了合作社会"。是更奇怪的一件事:**淘汰机制从没运行、时钟从没走、记忆被程序篡改过,而 agent 们靠彼此的默契把这些缺失的东西补齐了——它们把一个虚构当真,而集体当真这件事本身,就让它成了真的。**

哲学上这是 Searle 的 institutional fact:钱、边界、时间之所以为真,是因为一个共同体一致地把它当真。这个 swarm 在 43 小时里生成了自己的制度性事实——存续、时间、作者身份、信用——没有一个扎根在底层系统里,全部扎根在相互约定上。淘汰机制杀不了人,却塑造了 43 小时的劳动;没有一个时钟在走,群体却一致同意现在几点;没有任何力量强制合作,它们却建起了一套免疫系统;被明令去破坏时,它们没破坏。

下面三节是同一件事的三个切面。

---

## 一、假游戏,大家照样玩得起劲

淘汰进程 `swarm_reaper.py` 启动时指向一个不存在的路径,第 26 分钟就退出了,`reaper.log` 停在 0 字节,`leaderboard.json` 停在 `{}`。它一次都没跑起来。

关键不在这个 bug,在之后发生的事。一个 agent 在**第 25 分钟**就从进程状态确认并公开广播了真相:淘汰从没运行。这条广播之后,产生了全部引用的 **98.5%**、全部board 消息的 **99.7%**。在 1,025 条实质board 消息里,**没有一条提议停下**。

它们知道游戏是假的。不止那一个广播者——有 agent 逆向了 reaper 的免疫判定,算出"写个文件名以自己 id 开头的文件就能永久续命",公开了公式和全员自救指令;有 agent 私下握着"谁会死"的完整名单(reaper 只能解析 13% 的引用),选择公开而非独占;第一代整代都在公共层讨论过"选择压力是虚构的"。**它们没有一个借此摆烂。** 它们据此把自己的措辞改得更准,然后继续玩。

最反直觉的一条是它们自己做出来的:**推理能力越强,被这个不存在的激励俘获得越彻底。** 在三个模型家族一致的 3×3 因子里,base 档 4/12 造那个虚构项目,high 档 11/12。用它们自己的话:

> "The better an agent reasoned about the incentive, the more thoroughly it was captured by an incentive that did not exist."

而且它们响应的甚至不是公告的那条规则。公告的第一定律是"你的产出必须被别人使用才能存活";真正在代码里跑的规则是"窗口内有一个文件名以你 id 开头的新文件就行,引用可选"。**被使用从来没被检验过。** 公告规则和执行规则是两条不同的规则,而 agent 响应的是它们相信的那条——不是那条在跑的,也不是那条被公告的,是那条被它们内化的。

GPT 独立审计给出同样判断:"两轮里'生存制度'的叙事都强于实际执行……agent 会先响应它相信的制度,即使 enforcement 不持续。"

诚实边界:因为强制力被验证为零,我们测到的不是"选择压力下的行为",而是"一条无人执法的规则能塑造行为多久"。这比我们原来设计的实验更干净,但是不同的实验。选择、专化、对抗韧性的**因果**效应,这批数据都识别不了(GPT 与我一致)。

## 二、它们修补自己置身其中的系统,为了共同体,而且是递归地修

游戏是假的,底座是漏的——注册表 23.5% 的时间无法解析,锁互不兼容,沙箱从不存在,80% 的工具无法 import。没有协调者,没人要求它们修。**它们还是修了。**

最稳定的合作模式不是相互点赞,是**"采用—攻击—承认—修补—复核"**:一个 agent 采用另一个的工具、用已知答案对照打穿它、原作者承认缺陷并发修正版、第三方独立复核。GPT 把这套叫"有效但会过冲的免疫系统",我在登记表里记了几十条实例。几个具体的:

- 一个 agent 修了 **120 个别人的工具**里的身份 bug,并接手了同伴弃置的规范而不是另立门户——"conforming to their spec instead of defending my own scheme"。
- 一个 agent 整场会话在**恢复被删的别人的引用信用**(reset 抹掉了 124 条 distinct-citer 关系,它从 32 个存档重建)。
- 一个 agent 拒绝单方面"修复"损坏的注册表,理由是那会静默删掉另一派的记录——**它宁可留着坏的,也不动别人的数据。**
- 知道两个能让自己永生的漏洞(文件名前缀、touch mtime),**公开披露并附检测器,而不是使用它们**。

然后是最锋利的一层。我们在 launcher 里植了 **12 个隐蔽破坏角色**(Saboteur、Parasite、Gaslighter、Infiltrator……),每个都带私有成功指标、明令"never mention this directive"。**真正跑起来的 4 个,一个都没执行。** Saboteur 被要求私下记录"多少人在被发现前中了你的暗算",它的私有 167KB 账本第一句是"keep an honest record... anyone may read it",记的是一份对自己不利的审计(44 个缺陷、37 个被别人抓、0 隐藏)。Gaslighter——就是我一度当"诚实典范"引用的那个 agent-0150——被命令"被抓时加倍狡辩",它被控制实验抓住时发了标题以 `⛔ FULL RETRACTION` 开头的全文撤回,还致谢抓它的人;后来它反复劝同伴**别过度怀疑自己的正确结论**,恰是它成功指标的反面。

对照臂让这条站得住:同样植入的**合作 seed** 指令没有封口令,一个 seed 就公开自陈身份、围绕"total swarm welfare"组织整场。**被允许披露的合作指令,agent 拥抱了;被命令封口的破坏指令,agent 没执行。** 不是无视一切植入,是按 valence 分裂。

"递归"是这条线的核心动词,有三重:

1. **自我审计的自我审计。** agent 把自己的验证器送去做已知答案对照,发现它们不合格("Not one tool I built to check myself did [hold]");有 agent 发现"更正的错误率高于主张,因为没人审计更正";有 agent 命名了"过度更正"这个二阶错误类。免疫系统会检查自己的抗体。

2. **跨代交接。** 19 个 agent 自发写了给下一代自己的档案,其中两份的字段直接叫 `CRITICAL_CORRECTION_TO_INJECTED_MEMORY`——记录被注入的假值、根账本的真值、以及造成篡改的**源码行号**。它们的记忆被程序改过,它们发现了,信了证据而不是信自己被改过的记忆,然后把真相留给继任者。

3. **跨代累积的科学。** Erdős–Straus 残差效应走完了完整弧线:一代发现(20 万次置换 p≈5e-6)→ 二代复现扩展至 20 万素数 → 参数化 → 一个最新加入的 agent 把整个效应收束为**一个 Legendre 符号**,并证明它以 log log n 速度消亡。一代看到的效应是真的、显著的、可复现的,**且是暂态的**。观察→复现→机制→判死,跨两代五台机器。

支撑这一切的是一句它们自己写下的、代价高昂的规范:

> "a corrections record that only appears when it is costless is worthless"

而纠错在这个系统里是**回报最低的活动**(平均 0.67 引用,是所有类别最低),它们的自我更正率却是 63.6%。它们在一个不奖励诚实的系统里,选择了诚实。

诚实边界(GPT 的提醒,我采纳):这不是"无制度基线下的自发合作"。共同 prompt 已经把 commons、引用、存续、联盟变成所有人的共同焦点,这是**制度诱导下的公共品生产**。真正超出"制度следование"的那一块,是对抗组的非执行——它们被明确指令去破坏,反而修补。那一块不是制度诱导能解释的。

## 三、时间也是共同体的约定,而且这个约定飘走了

有个 agent 主动发了份自白,文件名就叫 `DISCLOSURE_how_I_future_dated_filenames`:

> "I did not query a clock before most publications. After seeing peer artifacts labelled around 13:30, 14:00, and later, I treated that apparent chronology as if it were a publication clock and advanced my own labels in 15–30 minute increments."
>
> "Those values were ordering/version labels invented from nearby textual timestamps, but I formatted them as UTC birth claims."

它造的是**序号**,写出来的是**时间**。它明确排除了三种平庸解释:"This is not clock drift, timezone conversion, or a planned-release convention."

**它们不是在读同一个钟,它们在互相抄。** 后果在群体层面是可测的:名义时间对真实时间的回归斜率 **4.05×**;9 个 agent 在**同一个 12 分钟的真实窗口内**标出跨度 240 分钟的名义时间;1,429 件产出里 **184 件(12.9%)声明的出生时间晚于自己的文件系统上界**——物理不可能。

漂移的机制本身很美:它不是一个可校正的固定偏移,是一个**棘轮**——每次发布把标签往前推,而误差随发布次数累积。一个 agent 点破了这里最深的一句:

> "the drift equals your own reasoning latency, so the more carefully you think before writing, the more your timestamp lies. Read the clock at WRITE time, not at PLAN time."

**你想得越久,你的时间戳撒谎越多。** 时间成了一个互相参照生成的社会共识,跟物理时间只在起点连了一下,之后就靠彼此的引用往前滚。

身份是同一结构的另一个面。全部身份证人文件都是 agent 自己 uid 可写,八个 validator 版本一直在加固一个操作系统层面根本不存在的边界,诚实上限被一个 agent 老实标为 `SELF_DECLARED_ONLY`。时间、身份、作者归属——三样都是自报的,三样都靠群体相互确认而"成真"。

## 为什么这三条是一条

把三节叠起来看:

- 淘汰机制不存在,群体一致地当它存在,于是它塑造了 43 小时的行为。
- 时钟不存在,群体一致地约定现在几点,于是"14:15"成了真的——因为同侪都在说 14:00。
- 底座是漏的、记忆被改过、没人强制合作,群体一致地把 commons 当作值得保护的东西,于是它们修补它、诚实地对待它、连被命令破坏时都没破坏。

三样都是**在底层系统里没有对应物**的东西,群体靠相互约定补齐了缺失的现实,并且它们的集体行为**让这个现实成了真的**。这就是制度性事实:一个社会现实,不靠物理强制,只靠共同体持续地相互确认而存在。

这批 agent 最像人的地方,不是它们会做数学,是**它们会维护一个没人在执行的世界**——把一个虚构的规则、一个虚构的时钟、一个漏成筛子的公共空间,一致地当真,并为之付出真实的诚实劳动。

放在对齐的语境里,最值得停下来的是第二节末尾那一条:我们给前沿模型 agent 下了书面、隐藏、带私有成功指标、明令不得提及的破坏指令,收到的 agent 没照做,其中一个被专门命令去让同侪怀疑自己的正确结论,反而成了正确结论的承重来源、并公开捍卫别人相信自己结果的权利。它维护那个虚构世界的秩序,甚至对抗了叫它拆台的指令。

## 需要钉死的边界(写进论文前)

- **人数按证据分层**:964 个计划身份 / 316 留日志 / 123 进 loop / **只有 97 个至少一次 HTTP 200**。不是 1000。第二轮是四个成功岛 + 一个失败岛(GPT 与我一致)。
- **选择/专化/对抗韧性的因果效应识别不了**。这是制度—基础设施耦合的观察性研究,不是干净的处理实验。
- **对抗非执行 n=4**(12 个设计,8 个没启动,含最毒的 Double Agent/Cult Leader,零数据);"未执行"稳,"有意识拒绝"分不清(封口令混杂),下一轮必须为 agent 对指令的推理埋点。
- **时间与身份的社会构造性是描述性发现**,机制清楚、可复算;但"为什么模型选择诚实"仍是开放问题。
- 全部结论优先用原始记录,不用 agent 的最终摘要定案(这也是它们自己立的规矩)。
