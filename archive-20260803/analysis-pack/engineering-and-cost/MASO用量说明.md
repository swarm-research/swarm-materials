## 一、结论

8/1 的消耗来自一个多智能体长程实验，**不是批量刷数据，也没有违规用法**。三个原因：

1. **长会话的二次方代价（主因）**——单会话跑到 300–485 轮，每轮把整段历史作为输入重发。10 个会话占掉 30% 的输入量。
2. **模型档位选高了**——两个最高推理档合计 62.5%，而 agent 多数时间在读写文件、跑脚本。
3. **缓存结构性失效**——实验要求每个 agent 上下文互不相同，与 prefix 缓存机制天然冲突。

问题在实验设计和监控缺失，不在平台。

---

## 二、任务性质

多 agent 自主行为观察实验（学术研究）：36 个 agent、三种模型、三档推理强度，**不预设目标、不给评分**，观察它们在竞争压力下是否自发分化出角色分工和协作结构。

**这类任务必然是长程的**——涌现结构需要 agent 反复读取彼此产出、二次创作、形成引用关系，跑十几轮什么都看不到。这是消耗大的根本原因，也是当时低估的地方。

## 三、消耗构成

> 口径：MASO 未记录逐条 token，按字符数估算（2.8 字符/token）。绝对值有误差，相对占比可靠。

### 按天

| 日期 | 会话 | 轮次 | 估算输入 |
|---|---|---|---|
| 07-21 ~ 07-31 | 783 | 19,745 | 1,925M（论文相关） |
| **08-01** | **63** | **10,339** | **1,952M（本次异常）** |
| 08-02 | 66 | 1,784 | 100M |

**8/1 一天 63 个会话，消耗超过此前 783 个会话总和。**

### 输入/输出比 = 247 : 1

总输入 3,976M，总输出 16M。**成本几乎全在重发的历史上，不是模型写了多少。**

### 二次方分布（核心）

第 N 轮输入 = 前 N-1 轮全部内容，N 轮累计是 O(N²)。

| 轮数 | 会话数 | 输入占比 | 单会话均值 |
|---|---|---|---|
| 0–20 | 446 | 4.3% | 0.39M |
| 20–50 | 315 | 19.3% | 2.44M |
| 50–100 | 92 | 16.7% | 7.22M |
| 100–300 | 49 | 29.6% | 24M |
| **300+** | **10** | **30.1%** | **120M** |

**10 个会话（1.1%）吃掉 30%。** 最贵单会话 485 轮、173M token。轮数翻倍，代价四倍。

### 按模型

| 模型 | 输入占比 |
|---|---|
| gpt56_sol_reasoning_xhigh | **46.4%** |
| gpt56_sol_reasoning_high | **16.1%** |
| es1_orange_o50_thinking_max | 8.8% |

## 四、cache 命中率为什么低

**排除**：不是 prompt 写乱了——129 个会话中 127 个的 system prompt 前 2000 字符完全一致。

**主因：可共享前缀在总量中占比可忽略。** 缓存要求前缀逐字节相同。共享部分（system prompt + 规则）只有几 KB；而每个 agent 从第 1 轮起就走向不同路径，到第 100 轮时私有上下文已达数十万 token 且互不相同。分母是几十万，分子是几 KB。这是"开放式自主探索"设定的直接后果。

**次因**：
- 36 个 agent 并发 = 36 份独立缓存条目，agent 之间无法互相命中，每份写入都有成本
- 实测 **20.4% 的轮次间隔超过 5 分钟**（中位 68s，p90 758s），超出常见 TTL 必然失效——原因是并发抢占，单 agent 两次调用间要等其他 agent
- 检测到 76 次上下文压缩，每次压缩使该会话缓存前缀整体失效

**两点说明**：
- 客户端侧读不到平台的缓存命中统计，以上是从会话数据反推。**若平台有逐请求 cache_read/cache_write 数据，可据此进一步核对各因素权重。**
- **即使缓存 100% 命中，二次方问题依然存在**——缓存降单价，不改变增长曲线。所以缓存不是主因，长会话才是。

## 五、后续改造方案

按节省幅度排序：

1. **限制单会话轮数**（50 轮切断起新会话）——按上表分布可砍 60% 以上
2. **降档**——探索类改用 seed-stable，仅关键环节用 xhigh
3. **重构 prompt**——公共内容严格前置且逐字节一致，私有信息后置
4. **规模换深度**——36 agent × 400 轮 ≫ 200 agent × 30 轮，后者便宜一个量级
5. **预算护栏 + 硬上限**——**这次最大的问题不是跑得贵，是跑了一整天没人发现**
