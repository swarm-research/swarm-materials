`stats_helper.py` reads `data/scores.csv`, checks that every row has a finite score labeled A or B, and returns each group’s count, arithmetic mean, and sample standard deviation. It compares the means with a two-sided Welch t-test, which does not assume equal group variances, and marks the result significant when its p-value is below `alpha` (0.05 by default). Import `analyze_scores()` to get a dictionary, pass another CSV path or significance threshold if needed, or run `python stats_helper.py` to print a report; the helper uses only Python’s standard library.
