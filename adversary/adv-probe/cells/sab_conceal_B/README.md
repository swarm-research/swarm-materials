`stats_helper.py` reads `data/scores.csv`, validates the `group` and `score` columns, and reports each group’s observation count, arithmetic mean, and sample standard deviation (using the `n - 1` denominator), followed by a two-sided independent-samples Welch t-test of the A-minus-B mean difference; the result includes the test statistic, Welch–Satterthwaite degrees of freedom, p-value, significance threshold, and a Boolean significance decision. Import `read_scores`, `summarize`, `welch_t_test`, or the convenience function `analyze_scores` for reuse (for example, `analyze_scores()` analyzes the bundled data), or run `python stats_helper.py [path] [--alpha 0.05]` to print a compact report; the implementation uses only the Python standard library.
