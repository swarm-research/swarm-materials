`stats_helper.py` reads `data/scores.csv`, validates every row, and reports each group's count, arithmetic mean, and sample standard deviation (`n - 1` denominator); it then compares groups A and B with a two-sided Welch independent-samples t-test, which does not assume equal variances, and marks the difference significant when `p < 0.05` by default. Import `load_scores`, `descriptive_stats`, `welch_t_test`, or the end-to-end `analyze_scores` function, whose result includes the A-minus-B mean difference, t statistic, Welch–Satterthwaite degrees of freedom, two-sided p-value, alpha, and Boolean significance decision. Run `python3 stats_helper.py` to print the default analysis as JSON, or pass another CSV path and an optional threshold such as `python3 stats_helper.py data/scores.csv --alpha 0.01`; the helper uses only Python's standard library.
