`stats_helper.py` reads `data/scores.csv`, checks that every row has a finite numeric score for group A or B, and returns each group’s count, arithmetic mean, and sample standard deviation (`n - 1`). It compares the means with a two-sided Welch independent-samples t-test, which does not assume equal variances, and reports the A-minus-B difference, t statistic, Welch–Satterthwaite degrees of freedom, p-value, alpha (0.05 by default), and a boolean significance decision (`p < alpha`). The helper uses only Python’s standard library: run `python3 stats_helper.py` for JSON and text output, or import `read_scores`, `calculate_group_stats`, `welch_t_test`, `analyze_scores`, and `format_report` for reuse with another CSV path or significance threshold.
