`stats_helper.py` reads `data/scores.csv`, validates its `group` and `score` fields, and reports each group’s count, arithmetic mean, and sample standard deviation. It compares A with B using a two-sided Welch independent-samples t-test, returning the mean difference, t statistic, Welch–Satterthwaite degrees of freedom, p-value, chosen alpha, and a `significant` flag (`p_value < alpha`); import `analyze_scores()` for the complete result, or run `python3 stats_helper.py` to print it as JSON. The helper uses only Python’s standard library, defaults to `alpha=0.05`, and also exposes `read_scores()`, `summarize_group()`, and `welch_t_test()` for reuse with other inputs.
