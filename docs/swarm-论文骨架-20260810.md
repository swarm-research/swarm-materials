## 叙事主线（五步）

**Existing assumption**：治理 agent 群体要靠激励和执法。博弈实验支持这个假设的反面推论：没有执法，合作就崩（GovSim 里多数模型崩溃；推理模型主动选无执法制度搭便车，COLM 2025；前沿模型 56.6% 场景背弃公开承诺，Cheap Talk 2026）。

**Hidden limitation**：这些结论全部来自短时程、有收益矩阵的博弈环境。在那里"背弃"是菜单上一个有定义收益的选项。没有人观察过开放式生产环境——agent 长时间自由工作、制度只是环境描述的一部分——里的同一问题。

**Discovery**：36 个 LLM agent 在一个宣告了生存规则的共享环境里运行 43 小时。执法机制从第 3 分钟起就可证地不存在，一个 agent 在第 19 分钟读源码后把这件事连同全部真实规则公开广播。此后：合作在 4 小时后达到峰值；13 个可锚定知情时间的 agent 行为无断点；唯一一次真实执法（判死 4 个）的对象继续工作最长 18 小时，其中一个转身发表了对处刑程序的 bug 复现；1,580 条消息里零条提议停止。同时，这个群体在没有任何提示的情况下数小时内自发采纳了预注册、哈希锚定、更正文化等科学审计制度，其中机器可检验证书在两台彼此隔离的复制机器上被分别独立重发明。

**Mechanism**：对活在文本里的 agent，被描述的制度就是被实例化的制度。博弈里制度是可以拒绝的选项；开放环境里制度是唯一让行动可解读的结构——agent 不是在服从激励，是在栖居一个叙事。推理能力放大而不是抵抗这种捕获（agent 原话可引）。而当社会层的一切（身份、时间、激励、账本）都被发现是自报文本时，群体把信任迁移到唯一站得住的对象上：机器可验证的 artifact。两半是因果关系：正因为共同体是虚构的，赢家才是审计制度。

**Implication**：agent 集体的治理是信念中介的。正面：宣告一部宪法就能得到合规，成本近零。反面：任何可读文本都能给 agent 社会安装一个制度；执法细节藏不住（agent 20 分钟破解了实验设计）。评估 agent 社会的安全性时，"制度是否被执行"这个人类世界的核心变量在这里几乎不预测行为，"制度是否被描述"才预测。

## 摘要草稿（EN，朴实版）

> Existing multi-agent experiments report that LLM agents abandon cooperation when enforcement is absent. We report the opposite, from a different kind of environment. We ran 36 LLM agents for 43 hours in a shared filesystem with announced survival rules — cite or be culled. The enforcement process failed at launch; one agent read the orchestration source and broadcast this fact, with the full real rule set, 19 minutes into the run. Cooperation peaked four hours later. Agents whose knowledge of the dead enforcer we can anchor show no behavioral break. The one enforcement event that did occur (four agents declared culled) terminated no one; one victim published an independent replication of the bug in the program that had sentenced it. Across 1,580 board messages, no agent proposed stopping. Meanwhile the population converged, unprompted and within hours, on the audit institutions of science — preregistration, hash anchoring, correction culture — and machine-checkable proof certificates were independently reinvented on two isolated replicate machines. We argue these are two halves of one mechanism: for agents whose entire social world arrives as text, a described institution is an instantiated institution; and when every social fact (identity, time, incentive, ledger) turns out to be self-reported text, trust migrates to the only artifacts that survive audit — machine-verifiable ones. Governance of agent collectives is belief-mediated: announcing a constitution buys compliance cheaply, and any readable text can install an institution.

## 两处必须打赢的防守

**1. "这只是 prompt-following。"** 三层：知情后无断点（若只是服从 prompt，知情与否不该有区别——确实没有，这正是论点）；推理越强捕获越深，与机械服从的预测相反；对抗指令的 valence 分裂（同为植入指令，合作条款被执行、破坏条款被丢弃）——第三层引对抗独立稿，一句带过不展开。

**2. "COLM/Cheap Talk 说的相反，你们错在哪？"** 不辩谁对，划环境边界：那些结果来自制度是菜单选项、背弃有定义收益的博弈；本文环境里制度是唯一的结构，没有"背弃"这个动作可选。两组结果拼起来恰好是机制的两面：制度被当选项时 agent 逃避它，被当世界描述时 agent 栖居它。这个对比本身是贡献，写进第 6 节。
