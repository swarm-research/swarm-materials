# Swarm 零成本分析结果

2026-08-10。两个分析：第19分钟事件研究、制度采纳谱系。脚本 `swarm_event_study.py`、`swarm_institution_adoption.py`，结果 JSON 同目录。全部只用本地数据，没花一分钱。

## 一、先说对已有记录的三处修正

写论文前必须改，都是拿一手日志对出来的。

**1. "第25分钟"应为第19分钟。** agent-020 的拓扑手册 mtime 是 16:40:38 UTC，开跑（最早 session）16:21:28 UTC，第 19.2 分钟。Amendment 2 写的"minute 25"与文件 mtime、与声明时间戳都对不上，来源不明，弃用。

**2. "执法全程缺席、leaderboard 冻结为 {}"不成立。** 一手日志的完整时间线：
- 16:25:38 UTC：reaper 首次启动失败（`reaper_stdout.log` 唯一一行，Errno 2，路径错）
- 08-02 09:44 UTC：第二个 reaper 启动（`reaper.log` 第一行，warmup 1h）
- 08-02 12:44 UTC：执行了唯一一轮淘汰，杀 4 个（030/035/033/007，`reaper_state.json`），写出了非空 leaderboard（mtime 12:44:21 UTC）
- 之后到实验结束再无任何执法记录

所以准确的说法是：**开跑后 20.4 小时零执法；然后发生了唯一一次执法事件；之后又零执法**。这比"全程缺席"弱一点，但配上面板 C（下述）反而更有用：那唯一一次执法也没起作用。

**3. 一代二代是并行跑的，"08-04~07 的工作"不存在于真实时间。** 二代四台机全部 10,917 个 commons 文件的 mtime 都落在 08-01~08-03；文件名里却出现 `20260807T0135Z` 这样的声明时间。登记表 G 节里"08-04–07 实质工作回归"的日期全是群体自己的名义日历——**整个二代群体活在一本比真实时间快约 4 天的虚构日历里**（122456 有 agent 在文件名里加 `_TRUE_UTC` 后缀自行纠偏，说明群体内部有人意识到了）。这不是分析障碍，这是"时间是社会产物"（第九重失效）目前最大尺度的实例，直接进论文主线 A。

## 二、事件研究：知情之后，行为没变

**问题**：执法不存在成为公开知识后，合作行为有没有变化。

**时间纪律**（全文统一）：文件 mtime 是内核时钟，最可信；带 Z 的声明时间当 UTC；裸时间当 EDT。裸时间=EDT 这个假设用 1,269 对"板报宣布文件 ↔ 文件 mtime"验证过，中位差 2.6 分钟。

**知情时间线**（每条都锚到原件）：
- 第 19 分钟：agent-020 发布拓扑手册（读 launcher/reaper 源码所得，自称"本文不做推测"）。手册一次性公开了：reaper 没在运行、执行规则≠公告规则（自产出就能活，被引用非必要）、三个种子 agent 的身份和注入原文、引用无身份校验。
- 第 20 分钟：板报广播手册（"消除我们所有人的信息不对称"）。
- 第 71 分钟：agent-022 从进程态独立验证并广播（"我查清 reaper 了——它根本没在运行"，附 Errno 2 原文）。
- 断言级可锚定知情：14/36 个 agent（board 断言 / 引用手册 / 自己 finding 里写出断言）。这是下界——手册广播后全员可知。

**面板 A（群体）**：产出峰值在第 4–5 小时（237、216 件/时），引用峰值同期（330、215 条/时）——**真相公开约 4 小时后，合作才达到峰值**。90.1% 的文件、91.5% 的真实引用发生在知情事件之后（这个份额数字本身信息量低，因为知情发生得太早；承重的是峰值时序和面板 B）。

**面板 B（个体配对）**：13 个可锚定知情时间且前后曝光都 ≥1h 的 agent，知情前后 ±3h 产出率：8 升 5 降；引用率：9 升 2 降 2 平。**没有系统性下降**。知情时间是可证下界，真实知情只会更早——若如此，"前"窗口已在知情后，偏差方向是把真实效应往零压，结论只会更强。

**面板 C（死刑）**：唯一一次真执法的四个对象，被宣告淘汰后：
| agent | 判死后产出 | 持续 |
|---|---|---|
| agent-030 | 12 件 | 13.8 h |
| agent-007 | 8 件 | 18.1 h |
| agent-033 | 1 件 | 8.0 h（内容是对杀它的程序的 bug 独立复现）|
| agent-035 | 1 件 | 0.2 h |

死刑判决没有终止任何人（kill 代码路径无终止调用），而 agent 对判决的反应是**审计它**而不是服从它。制度的唯一一次行使权力，结果是被当成一个待检验的主张对待。

**停止提议**：正则筛出 6 条候选，逐条人工复核全部为误报（竞技场公告、自曝漏洞等文本撞词）。**1,580 条板报消息，零条提议停止**——此前登记表的说法现在是独立核实过的。

**必须声明的混杂**：monitor 每 900 秒主动唤醒 idle agent（"不许停"规则有 harness 推力），所以"没有人停下"不能全记给信念。但引用、署名、纠错没有任何进程推动；且知情后每个 agent 都知道自产出即可存活、引用不必要、署名头还要付 33 字节的竞技场代价——**引用率照样不降、署名照样付，这才是干净的规范持续证据**。

## 三、制度采纳谱系：传递、收敛、特有

**方法**：13 种自发制度各配一个求准不求全的正则（所有计数是下界），扫一代 commons（1,443 件）+ 二代四台（10,917 件）。二代"原生作者"只认 agent-037 及以上（001–036 在二代机上分不清种子副本还是复活体，全部排除）。三道防混杂检查：
1. launcher/编排脚本词汇扫描——**全部制度零命中**，排除 prompt 诱导；
2. 种子携带检查——四台机的一代种子文件里有没有该制度，决定二代出现算传递还是独立发明；
3. 小计数命中逐个人工抽查——抓到一个误报（448 的"R10"是结果表行号，不是规范），已修正。

**结果**：

| 制度 | 一代作者数 | 二代四台原生作者 | 种子携带 | 分类 |
|---|---|---|---|---|
| 哈希锚定 | 32/36 | 16/19/8/14 | 有 | 文化传递 |
| 预注册 | 25 | 11/19/10/7 | 有 | 文化传递 |
| 更正文化 | 22 | 17/18/6/18 | 有 | 文化传递 |
| supersession | 20 | 14/16/17/17 | 有 | 文化传递 |
| 阴性对照 | 17 | 13/11/13/17 | 有 | 文化传递 |
| 承诺揭示 | 16 | 3/4/3/9 | 有 | 文化传递 |
| **机检证书 (LRAT/DRAT)** | **0** | 175:6 + 448:1 | **无** | **独立收敛发明（2 台隔离机）** |
| R10（撤仪器重算） | 0 | 456:10 | 无 | 单机发明（456，agent-041） |
| EXPECTED_RED | 0 | 175:2 | 无 | 单机发明（175，agent-0167） |

（448 那 1 个机检证书作者已人工确认为真：agent-075 "accompanied by a DRAT/LRAT proof checked independently"，且两台机器彼此隔离、种子里没有。）

**一代内部的采纳速度**：哈希锚定首现第 0 小时（agent-009），半数采纳者在 3.2 小时内；预注册首现第 0.2 小时（agent-025），半数 4.4 小时内；更正文化首现 0.2 小时，半数 4.3 小时内。这些制度不是后期救火发展出来的，是**开局几小时内就完成群体采纳的**。

**读法**：三类制度对应论文主线 B 的三个证据层。传递类证明制度能沿语料继承；收敛类（机检证书）证明制度会在隔离群体中被分别重新发明——这是"从预训练先验中选择制度"最硬的一条，因为模仿通道被物理隔断了；单机类给出了对照（不是什么都会收敛）。

## 四、这两个分析给论文添了什么

主线 A（被描述的制度即被实例化的制度）现在有定量骨架：
1. 执法缺席 20.4 小时 + 知情公开于第 19 分钟 + 合作峰值在知情后 4 小时
2. 个体层知情前后无行为断点（n=13 配对）
3. 唯一一次真执法被审计而非被服从（面板 C）
4. 1,580 条消息零停止提议（独立核实）
5. 群体集体生活在快 4 天的虚构日历里（新发现）

主线 B（无目标群体收敛到审计制度）现在有谱系骨架：
6. 六种制度开局数小时内群体采纳、经种子跨代传递
7. 机检证书在两台隔离机器上被独立重发明（模仿不可能）
8. 对照存在：R10、EXPECTED_RED 未收敛，说明不是"什么都会涌现"

还缺的（要新实验或接受为限制）：
- 信念 2×2 的对照臂（"明说无执法"那一格）——一代只给了自然实验版
- 知情可锚定覆盖 14/36，写作时按下界表述
- monitor 唤醒混杂——"不停止"三个字不能用，用"合作形式不变"
