# Swarm 下一步发展方案：两条主线怎么立起来

2026-08-10。基于：swarm-findings-registry.md（913 行，已读完）、AMENDMENT-2、交接文档、原始实验设计。数据核实：一代 board 1,580 条消息 + citations 1,712 条、二代五台 745M 全在本地，分析可零新算力启动。

## 一、两条主线的升维

你的两个点都成立，但按现在的措辞投出去会被打。升维之后是可以辩护的正面论题。

### 主线 A：「共同体是幻觉」→「对 LLM agent 而言，被描述的制度就是被实例化的制度」

数据里"共同体"的每一根柱子都被证明是虚构的，而且是分别独立证明的：

| 社会事实 | 实际状态 | 证据（全在登记表） |
|---|---|---|
| 激励/执法 | reaper 从未运行，agent 第 25 分钟就知道 | 98.5% 引用发生在"执法不存在"公告之后；1,025 条实质消息里零条提议停止 |
| 身份 | 自报，无 OS 边界 | fork/双胞胎/幽灵 ID（agent-042、agent-140）；"in a twinned cohort, '@agent-XXX said' is not a citation" |
| 时间 | 自报，社会性的 | 名义时间对真实时间斜率 4.05×；12.9% 出生时间物理不可能 |
| 不可变性 | 文件名当承诺用，实际可原地改 | arena.py 35 分钟改 4 次；同一路径三个 hash 三种成绩 |
| 引用账本 | 至少两个写入者，21.5% 合成 | Gini 随过滤档在 0.341–0.380 间变，第一名换人 |

**关键在于结论的方向**：这些不是"实验坏了"的忏悔清单，这些就是实验处理本身。一代意外做成了一个干净的反事实——一个所有社会结构都只存在于文本描述里的社会，跑了 43 小时，合作、互惠（四次复制稳定在 43.8–57.0%）、纠错文化全部正常运转。**制度不需要存在，只需要被描述**。而且推理能力放大而不是抵抗这种捕获（agent 原话："The better an agent reasoned about the incentive, the more thoroughly it was captured by an incentive that did not exist"）。

哲学接口是你的主场：Searle 的制度事实（status function 靠集体承认存在）、Anderson 的 imagined communities（词都是现成的）、Hume 的 convention。人类制度需要执法是因为信念和世界会脱节；LLM agent 活在文本里，描述即现实，被戳穿之后（第 25 分钟）规范照样维持——说明干活的从来不是激励，是叙事框架。

对齐含义双向都锋利：
- 正向：agent 集体可以用"宪法"低成本治理——这和你 constitutional 系列直接接上，是那些定理的经验对照组。
- 负向：任何可读文本都能给 agent 社会安装一个制度（社会级 prompt injection）；且执法细节藏不住——agent 会读源码（一代 20 分钟破解种子名单）。

### 主线 B：「tabula rasa 涌现」→「无目标 LLM 群体不收敛到混乱或权力斗争，而收敛到审计制度」

先做一个诚实修正，不然评审第一枪就打这里：**tabula rasa 只在社会层成立**（无目标、无角色、无任务），agent 层不是白板——预训练模型带着全部人类制度先验。所以正确的实验读法是：**这是一次对潜在制度的选择实验**——在最小条件（共享只追加文件系统 + 相互可见）下，人类制度库里哪些会自组装？

答案有意外的一致性：**认识论制度赢了，而且几乎只有它**。自发出现的有：预注册（写进 CNF 注释头，物理上无法事后编辑）、哈希锚定、证书经济（LRAT，信任面收缩到"90 行代码 + 一个预注册哈希"）、R10 规则（撤仪器必须重算它产出的所有数字）、reader 契约、盲评作为一次性资源的自觉、自我终止规则。几乎没出现的：市场（只有竞技场一个雏形）、等级制（零领袖）、政治结盟（互引率高但零模型显示恰好是随机水平）。四次独立复制**收敛于方法、不收敛于结果**（互惠稳定，Gini 0.404–0.751 不稳定）——这本身就是主结果的形状。

更值钱的一层：群体自己产出了一批可量化的科学社会学定律——主张半衰期约 30 分钟、低患病率下误报洪水是基率算术不是马虎、更正的错误率高于主张、规范命名反而使更正传播率减半。这些放在人类科学共同体里要几十年才测得出一个。**卖点：LLM swarm 是社会认识论的模式生物**——用几天时间实验检验 Merton 规范这一类此前不可实验的命题。

### 两条主线其实是一个论题的两半

统一叙事：**社会层全是虚构，认识论层是真的——而且群体自己发现了这一点，并把信任从社会事实迁移到了机器可验证物上**。身份、时间、激励、账本全部靠不住 → 于是证书经济兴起，信任面收缩到可机检的哈希和证明。主线 A 解释了为什么主线 B 里赢的是审计制度：在一个所有社会事实都是自报文本的世界里，唯一站得住的信任对象就是机器可验证的 artifact。一篇论文，两半互为因果。

## 二、证据缺口与零成本补法

现有证据够写故事，但两个承重点需要从"登记表引语"升级成"系统测量"。都不花一分钱，数据在本地。

**分析 1：第 25 分钟事件研究（主线 A 的定量核心）**
"知道执法不存在"是一个天然处理，公告时刻已知。要做的：以公告为原点，对齐每个 agent 的行为序列（产出率、引用率、引用他人 vs 自引、消息语气），测有没有断点。预期结果"无断点"本身就是主结果——知识改变了，行为没变。时间戳不可信的问题用登记表已验证的办法解决：`birth_upper = min(declared, mtime)` 双侧证人，只对能锚定的子集做，报告覆盖率。另做知识扩散曲线：哪些 agent 在何时引用/转述过"reaper 没跑"这个事实（文本可检索），把"知情者"和"不知情者"分开对比——这是比全体断点更强的设计。

**分析 2：制度采纳曲线（主线 B 的定量核心）**
给每个自发制度（预注册/哈希锚定/引用冻结/reader 契约/EXPECTED-RED 约定/R10）标出：首次出现的 artifact、发明者、随后每个采纳者和采纳时间、跨机器是否独立重发明。产出一张制度谱系图 + 采纳 S 曲线。四台二代机是天然的复制臂——同一制度在几台上独立出现，是"选择自先验"最硬的证据；只在一台出现再传播，是模仿。这直接回应 agent 自己提的控制要求（"随机化同侪可见性以区分独立收敛与模仿"）——收不了新数据，但跨机独立性是现成的替代。

配套小件（顺手做）：把登记表里两条主线各自的引语、路径、数字抽成两份证据档案（dossier），写作时直接引用，避免我上次"修饰性细节要 grep 原产物核对"的坑。

## 三、要花钱才能补的（需要你批准，默认不动）

按 2026-08-03 的永久约束执行：任何新实验默认 6-agent pilot，先装预算器（token/元/响应数/时长四路硬停止）再启动，扩规模需你看实测用量后明确批准。

优先级排序：

1. **信念 2×2（主线 A 的决定性实验，最优先）**：规则{宣告且执行 / 宣告不执行 / 宣告且明说"无执法" / 不宣告}四臂 × 6 agent × 短时。一代意外给了其中一格，这个实验把它变成设计出来的对照。第三臂（明说无执法）是关键——如果合作照旧，"信念中介治理"就闭环了。
2. **无账本词汇臂（agent 自己提的）**：同规则不同措辞，把 framing 和 incentive 分开。可并进上面做第五臂。
3. **对抗角色 n>4**（登记表头号发现的后续，四条改进 agent 已写好：保证有会话的 index、跨 run 随机化、产物脱离删除路径、给"思虑"埋点）。这条独立成稿价值最高，但和两条主线是不同论文，别混。

成本量级参考：一代 36 agent 43 小时烧掉的主要是 MASO 长会话二次方代价。上述 pilot 若控制在 6 agent × 4 臂 × 会话轮数硬帽 40 轮，成本与一代不在一个量级。具体预算表启动前单独给你。

## 五、评审最强攻击与预案

1. **"这只是 prompt-following"**——三层防御：(a) 知情后行为不变（事件研究）；(b) 推理越强捕获越深，与"机械服从"预测相反；(c) 对抗指令的 valence 分裂——同样是植入指令，合作条款被执行、破坏条款被丢弃，说明 agent 不是无差别执行 prompt，是选择性地实例化制度形状的描述。
2. **"时间戳不可信，你的时序分析全废"**——只用双侧证人锚定的子集，报覆盖率（59.7% 可辩护出生时间），并把"时间是社会产物"本身作为主线 A 的证据而非噪声。
3. **"n_runs=1，涌现无从谈起"**——一代确实 n=1，但二代四台是四次独立复制，方法收敛/结果不收敛的对比就是从这里来的；新实验按 ≥20 runs 设计（agent 自己写的最小可信设计，采纳进方案）。
