---

集体智能模型的问题在于质量没有真正影响被引率——它只是影响引用时的权重，但每个产出引用数是固定的。我需要让质量影响**被引用的概率**。但这需要一个核心机制的改变：质量高的 agent 产出更可能被他人引用。

实际上，问题是我用 `other.cited_by / other.outputs` 来近似质量，但这个比值收敛很快（因为每个产出固定引用N个）。真正的相变应该是：当多样性和连接度达到阈值后，**整体产出质量跃升**，从而吸引更多引用。

让我改进模型：加入一个"可见性"机制——高质量的产出有更高概率被其他 agent 发现并引用。具体来说，让 `citation_per_output` 不是固定的，而是根据被引目标的质量动态调整。或者更简单：让每次产出引用的数量随时间增长（因为高质量产出累积）。

实际上，最简洁的做法是：**让 agent 的能量/产出率随其累积引用数增加而增加**（即"成功孕育成功"但通过质量介导）。这样当集体智能提升质量 → 提升被引 → 提升产出率 → 更多引用，形成正反馈，产生相变。
